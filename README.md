# Login Account Avatar & ID Blur

クラウドワークス・ランサーズ・ココナラ・Workana で、**ログイン中のアカウント自身の**アバター画像と ID／ユーザー名だけにぼかしをかける Chrome 拡張機能（Manifest V3）です。
画面共有・スクリーンショット・録画のときに、自分のアカウントが特定されるのを防ぎます。他のユーザーのアバターや名前はぼかしません。

| 対象サイト | ドメイン |
| --- | --- |
| クラウドワークス | `crowdworks.jp` |
| ランサーズ | `lancers.jp` |
| ココナラ | `coconala.com` |
| Workana | `workana.com` |

（いずれもサブドメインを含む）

おまけ機能として、**DeepL 翻訳（`https://www.deepl.com/…/translator`）をダークモードで表示**できます（初期設定で ON。ポップアップの「DeepL 翻訳をダークモードにする」で切り替え）。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. すでに開いている対象サイトのタブは再読み込みする

## 使い方

1. 対象サイトにログインした状態でページを開くと、ヘッダーのアバターとユーザー名／ID が**自動検出**され、ぼかしがかかります。
2. ツールバーのアイコンからポップアップを開くと、次の操作ができます。
   - ぼかしの ON/OFF、ぼかしの強さ（2〜20px）の変更
   - 検出・登録済みのアバター画像と ID／名前の確認と削除（サムネイルはマウスを乗せたときだけ表示）
   - **要素を選択してぼかす**: ページ上の要素をクリックして手動登録します（画像ならアバターとして、テキストなら確認ダイアログで編集してから ID／名前として登録。Esc でキャンセル）
   - ID・名前、または画像 URL の直接入力
   - 再検出、このサイトの登録の全削除
3. 検出結果はサイトごとにブラウザ内（`chrome.storage.local`）にだけ保存されます。外部への通信は一切しません。

## 仕組み

- **自分の特定**: ページ最上部のヘッダー領域から、小さな正方形または丸いアバター画像を探します（クラス名・alt・位置からスコアを付けます）。そのユーザーメニュー内のユーザー名要素、プロフィールリンク（例: `/public/employees/…`、`/profile/…`、`/users/…`、`/freelancer/…`）、画像の alt から名前／ID を取り出します。ヘッダーには自分の情報しか表示されない、という前提を使っています。
- **画像のぼかし**: 登録したアバター URL からキー（パス、サイズ接尾辞を除いたファイル名）を作り、`img[src*=…]` などの CSS ルールでぼかします。後から読み込まれた画像やサイズ違いの同じ画像にも効きます。
- **テキストのぼかし**: ページ内のテキストから ID／名前を探します。要素の中身がほぼ名前だけ（「さん」などの敬称程度）ならその要素に `filter: blur` をかけます。文章の一部に名前が出てくる場合は CSS Custom Highlight API でその部分だけを伏せます。テキストノード自体は書き換えないため、React や Vue で作られたページの動作を妨げません。
- `MutationObserver` で、SPA の画面遷移や動的に追加された要素にも追従します。
- **Shadow DOM 対応**: ココナラのヘッダーは Web Components（Lit）で作られており、アバター（`img.userMenu_iconImage`）やユーザー名（`.userMenuListUser_name`）が Shadow DOM の中にあります。検出・テキスト走査・変更監視は shadow root の中まで辿り、ぼかし用 CSS も各 shadow root に挿入します（ページ側の CSS は Shadow DOM 内に効かないため）。
- **DeepL ダークモード**: DeepL のクラス名は頻繁に変わるため、ページ全体の色を反転（`invert` + `hue-rotate`）して暗くし、画像・動画は再反転して本来の色で表示します。

## ファイル構成

```
manifest.json
src/sites.js     サイト定義（セレクタ・プロフィールURLのパターン）と共通処理
src/content.js   検出・ぼかし・要素選択モード
src/deepl-dark.js DeepL 翻訳のダークモード
popup/           ポップアップ UI
icons/           アイコン
```

## 注意・制限

- 各サイトの HTML 構造は予告なく変わります。自動検出がうまくいかない場合は、ポップアップの「要素を選択してぼかす」で登録してください。サイト固有のセレクタは [src/sites.js](src/sites.js) で調整できます。
- 間違った項目が自動検出された場合は、ポップアップの × で削除できます。誤検出が続く場合は、自動検出をオフにして手動登録だけを使ってください。
- アバターが各サイトのデフォルト画像（未設定）の場合、他のユーザーまでぼけてしまうのを避けるため、自動では登録しません。
- 数字だけのユーザー ID（URL にだけ含まれるもの）はテキストのぼかし対象にしません。
- ページの最初の表示時に、一瞬だけぼかし前の状態が見えることがあります（初回の検出前は特に）。
- タブのタイトル、テキストのコピー、ページのソースからは元の文字列を読み取れます。ぼかしは見た目だけの処理です。
